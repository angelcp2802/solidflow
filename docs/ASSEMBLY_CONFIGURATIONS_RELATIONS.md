# Effective relations in rigid configuration states

The standalone [independent geometry verifier](ASSEMBLY_CONFIGURATIONS_VERIFICATION.md)
uses a fresh native inventory at every actual placed scope. Its detached reports
do not supply configured solve execution, persistence or Apply authority.

The [configured numerical scope](ASSEMBLY_CONFIGURATIONS_SCOPE.md) consumes
these same private aggregates only in their exact placed declaring namespace.
Grouping reusable intrinsic states never merges distinct occurrence proofs.

Optional named [capture/winding overrides](ASSEMBLY_CONFIGURATIONS_STATE.md)
are applied by the core before this inventory is built. Effective mate values
therefore retain the selected state's captures and lifted angles without
changing source declarations or granting native recapture authority.

This standalone layer follows the [configuration core](ASSEMBLY_CONFIGURATIONS_CORE.md)
and [native query context](ASSEMBLY_CONFIGURATIONS_NATIVE.md). It inspects the
selected occurrence states and resolves the current saved relation families
against their actual native geometry. It does not solve those relations or
change the saved v2 format, production worker, editor or Apply authority.

## Declaration inspection

`inspectAssemblyConfigurationMateReferences(document, catalog, rootConfiguration)`
validates and owns its inputs through the configuration core. It walks effective
scopes and mate declarations, including inherited scope suppression and named
mate overrides. Inspecting only the base source would lose those overrides.
Visibility affects display, without disabling material or equations.

Each frozen record carries the full scope path, exact scope tuple, selected
configuration, configuration ancestry, declared effective scope pose, scope and
combined suppression flags, mate and ordered roles. A role retains its original
reference, candidate and diagnostics. Repeated references stay repeated. A null
carrier is an explicit declaring-scope frame; it is not an absent role or a new
fixed world anchor.

Candidates use effective occurrence chains and poses. Their definition remains
the owned source declaration; it is not a substituted assembly document.
Continuing a path must use effective scopes rather than walking that base
definition's occurrences. Diagnostics distinguish
missing occurrences, traversal through a part, stale tuples and suppressed
components. Part topology declarations also check their feature producers and
explicit body state. Compound profile/path roles inspect both face/edge or
edge/start-vertex declarations, without replacing their joint native incidence
check. No display name, nearby face or equal geometry repairs a reference.
Source hierarchy and expanded declaration budgets remain unchanged.

The inspection remains declaration data with `nativeVerificationRequired: true`.
A candidate, empty diagnostic list, copied inspection or evaluation DTO grants
no native reference, satisfaction, solver or Apply authority.

## Current native aggregates

The configured snapshot derives its own effective inventory. Public methods
accept the complete `{document, catalog, rootConfiguration, generation}` input;
they do not accept caller-authored inspections or observation callbacks.

| Method | Boundary |
| --- | --- |
| `resolveActiveMates` | All effective equations in active scopes, after declarative preflight of the entire active selection. |
| `inspectGearState`, `inspectScrewState`, `inspectRackPinionState` | Resolved and declaratively unavailable state in active scopes, optionally restricted to effectively suppressed equations. |
| `resolvePassiveGears`, `resolvePassiveScrews`, `resolvePassiveRackPinions` | The suppressed-equation selection of those state inspections. |
| `assertResolvedMate` | Exact privately issued aggregate identity, complete current input and each owned child witness. |

The selection covers every currently saved family: concentric, coincident,
distance and distance stops; angle, principal/directed angular stops,
parallel and perpendicular; plane/cylinder, cylinder/cylinder and all existing
sphere tangencies; component lock, gear, screw and rack/pinion; four-plane
centered width; all five symmetry forms; circular and rectangular profile
centers; material LINE/circular paths with optional UP; and four/six-role
hinges. This does not introduce additional relation families or Width modes.

Aggregates retain the exact effective declaration and full scope identity.
Their witnesses preserve document-root rigid owners even in nested scopes.
Direction-only angular roles cannot grant positional or radius authority.
Surfaces remain distinct from axes, bounded profiles from generic planes, and
material path origins from generic curve parameters. A null gear carrier uses
the actual configured declaring frame. Hinge axis/axial roles and optional
angular stops must have the corresponding analytic purposes and root owners.

Closed helpers compose observation data only. The class checks the complete
context after processing and before private issuance. Aggregates cannot be
created by cloning another result, assembling genuine child witnesses into a
new object, calling an observation helper, using a different session or passing
a legacy proof. The native registry is independent of the legacy solver.

Within an atomic internal sequence, already frozen child identities are checked
directly against their private owner registry. That lookup admits no new input
and invokes no callback. Complete current-input checks still bracket aggregate
authentication and remain before/after native processing and on public witness
assertions; the document need not be re-evaluated for every private lookup.

## Failure, precision and remaining integration

Active declarative diagnostics reject resolution before the first native role
query; repair inspection remains possible in the current session. Passive
state inspection returns declaratively unavailable entries without silently
changing their equations. A suppressed scope excludes its whole namespace;
an effectively suppressed equation in an active scope still has passive state.

Native processing or aggregate-purpose failure revokes the configured context,
releases its owned prototypes and withholds the entire result. It cannot be
converted into an ordinary unavailable entry and followed by partial output.
Currentness is checked for empty and unavailable-only results too. Current
input mismatch permanently revokes all issued references and aggregates.

Reference resolution retains the existing native query precision policies and
effective placement arithmetic. It does not certify relation satisfaction,
hinge axial qualification, path following, physical contacts or a solved
configuration. The separate [numerical bridge](ASSEMBLY_CONFIGURATIONS_NUMERIC.md)
maps these roles to detached constraints and adds bounded independent
hinge/profile/path support measurements with the original bands preserved.
Those adapters do not turn this inventory into production configured solved
state, native capture transactions or Apply authority.

Solving and writing back by source tuple plus selected configuration, variant
native capture/winding continuity, saved syntax, direct base selectors, all source/repair/BOM/
export/editor consumers and independently solved flexible instances remain
required. Read [actual validation](VALIDATION.md) and
[fixture provenance](PROVENANCE.md) for executed cases. Configured tests or
this inventory do not establish external parity, hosted execution, installed
packages, other platforms or the complete assembly/demo scope.
