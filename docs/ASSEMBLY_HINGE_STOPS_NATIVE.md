# Native references for explicit hinge angular stops

This standalone bridge connects the [numerical six-role hinge](ASSEMBLY_HINGE_STOPS_NUMERIC.md)
to current native analytic supports and an independent physical measurement.
The standalone APIs grant no saved editing or private Apply capability. The
[saved extension](ASSEMBLY_HINGE_STOPS.md) composes them with that lifecycle. The
explicit directed coordinate is a mathematical contract; external angle origin,
selection order, signed/range and toggle policies still require evidence.

## Six current references

`AssemblyLimitedHingeReferenceRequest` preserves the original ordered axis and
axial pairs and alignment. Its separate `stops` field declares
`coordinate: 'directed-about-axis'`, two ordered material planar faces and an
explicit start/sweep arc in degrees. Angular principal-plane datums are outside
this standalone material-face contract. Syntax validation grants no native
authority. The saved extension uses the same strict request validator; the
four-role standalone request boundary remains unchanged.

`resolveAssemblyLimitedHingeReferences` resolves all six current references
before issuing a frozen aggregate. Each angular plane shares its side's actual
document-root rigid owner, although axis, cap and angular descendants may
differ. Scope selects a context; it does not promote nested children into
independent bodies. Equal coordinates or matching labels cannot bind a face.

The aggregate is privately tied to its exact issuing snapshot and unchanged
document. Copies, other snapshots, changed sources, disposed snapshots and
reentrant changes during the last query reject. Every final assertion checks
the four original witnesses and both angular witnesses. A valid resolution
failure closes the borrowed snapshot; a cleanup failure remains visible beside
the original error. Malformed syntax rejects before native queries.

The internal base-proof composition bridge exposes only the already-issued
four-role authority after checking all six witnesses. It does not attest an
angular stop, saved relation, transaction or Apply capability.

## Detached numerical intent

`buildAssemblyLimitedHingeConstraint` retains all six current supports, actual
rigid owners, descendant frames and separate uncertainty records. It preserves
original placement magnitudes and depths before cancellation. Position errors
include native support tolerance; direction errors remain angular and do not
come from a positional tolerance. Angular-plane positions are not extra joint
constraints. The builder does not certify interval membership, projection
observability or a degree count.

Its detached declaration can be passed to the numerical solver/projection
layer. After changing a candidate placement, native final measurement requires
a fresh candidate snapshot. A report or copied declaration cannot replace that
measurement or become a private editing capability.

## Independent physical verification

`measureAssemblyLimitedHingeReferences` makes six fresh queries. It composes
the existing independent four-role physical hinge check with a separate phase
measurement from the two current angular normals and the first material axis.
The four-role resolved measurement helper leaves failure cleanup to its fresh-
query caller, so each public path has one owner of failure cleanup.

For unit normals a,b and guide g, the native verifier directly calculates
`x = a dot b - (g dot a)(g dot b)` and `y = g dot (a cross b)`. Their `atan2`
gives the phase without normalizing projected normals. This path does not call
the numerical phase helper, its derivatives, solver rows or solved rank.
Independent native material vertices, literal trigonometric rays and original
mass/bounds establish physical checks; two implementations of a floating-point
formula alone are insufficient evidence.

Finite direction balls bound the raw dot/triple errors and therefore the phase
disk. Both projections must remain distinguishable from zero. Original chain
depth, direction normalization and Float64 composition remain charged. The
phase and interval endpoints use a separately calculated centred lift, with
rejection at unresolved conversions or uncertainty crossing the chart cut.
Full circles have no seam stop but still require an observable angular phase;
equal endpoints differ from a full circle.

An `ok` report contains finite measured angle, margins, direction error and the
independent hinge report; `satisfied` requires both parts to fit their requested
bands. The default bands remain 1e-6 mm and 1e-8 rad. A nominal near-bound fit
whose remaining band cannot contain its retained error returns `precisionLimit`
without partial angle or satisfaction fields. An observable interval violation
can instead return `ok` with `satisfied: false`. No band is widened.

## Evidence and remaining integration

Original native tests cover both endpoints/interior, native-derived restoration
and projection release, transformed/oblique frames, reused/nested owners,
sixth-query and cleanup failures, current-proof lifetime and independent
material/mass/bounds/BRep checks. Fixture origins and exact formulas are in
[provenance](PROVENANCE.md#original-native-six-role-hinge-controls); executions
belong in [validation](VALIDATION.md).

[Saved integration](ASSEMBLY_HINGE_STOPS.md) supplies a separate six-role
declaration, worker/editor lifecycle and repair contract, with its own tests
and execution record, including a separate bounded local-Z pointer workflow.
General pointer/interval combinations and externally evidenced angular
policies still require separate acceptance.
This support-only standalone bridge does not establish trimmed-face contact,
continuous collision freedom, full assembly/demo acceptance or another platform.
